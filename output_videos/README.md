# Badminton AI - Output Videos

This directory contains the processed match videos generated by the Badminton AI tracking pipeline.

## Video Outputs

| File | Description | Tracking Coverage | Features |
|---|---|---|---|
| `00467_players_and_shuttle.mp4` | Full Match Video | 100% players, 98.9% shuttle | Red bounding boxes (`Player 1` & `Player 2`), racket detection, and shuttle trajectory. |
| `00467_shuttle_tracked.mp4` | Dedicated Shuttlecock Telemetry | 98.9% (271/274 frames) | Broadcast gradient trajectory flight arc, real-time speed in km/h, and status HUD. |

## Generating New Video Results

To generate video outputs for any new match footage:
```bash
# Full match analysis (Player 1 & 2 in red + shuttlecock)
python yolo_inference.py path/to/video.mp4 --person-model yolov8n.pt --output output_videos/match_result.mp4

# Dedicated shuttlecock trajectory & speed tracking
python detect_shuttle.py path/to/video.mp4 --output output_videos/shuttle_result.mp4
```
